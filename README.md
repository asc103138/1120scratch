# 1120scratch｜《王子折箭》Scratch 3.0 教學動畫專案

依國小四年級上學期國語第九課《王子折箭》課本劇本（P98–100）製作之 Scratch 3.0 線上版動畫檔案與課堂分鏡對照文件。

## 專案檔案
- `王子折箭_第一幕.sb3`：第一幕 Scratch 3.0 線上版動畫（純向量 SVG 角色場景＋內建 WAV 音效＋同步固定字幕條）。
- `王子折箭_第一幕_分鏡與廣播對照表.md`：第一幕角色清單、廣播訊號時間軸與第二幕串接說明。
- `rdq/RDQ-spec-prince-arrows-act1-20261119.md`：RDQ 需求規格卡（已確認）。

## 使用方式
1. 開啟 [Scratch 3.0 線上編輯器](https://scratch.mit.edu/projects/editor)。
2. 點選 **檔案 → 從你的電腦挑選**，載入 `王子折箭_第一幕.sb3`。
3. 點擊右上角 **綠旗** 即可自動播放第一幕。
